> [!WARNING]
> **Experimental Research Prototype (`v0.1-preview`):** This model is an early research proof-of-concept for ultra-compact, on-device Malayalam speech synthesis. It is **not a finished commercial voice**. While intelligible and extremely lightweight (~10 MB), it exhibits synthetic timbre artifacts inherent to low-parameter source-filter vocoding. See [Current Status & Known Limitations](#current-status--known-limitations) below.

**Tui Voice Mini Malayalam (`tui-voice-mini-ml`)** is an experimental, ultra-compact Malayalam Text-to-Speech (TTS) neural research model. Fine-tuned from [tiny-voca](https://github.com/n4ze3m/tiny-voca) on high-fidelity studio recordings from the [AI4Bharat Rasa](https://huggingface.co/datasets/ai4bharat/Rasa) Malayalam female corpus, it explores the lower limits of neural speech footprint with just **4,537,291 parameters (~10 MB footprint)**.

Unlike conventional neural TTS pipelines (e.g., FastPitch + HiFi-GAN at ~110M params or Meta MMS-TTS VITS at ~36M params) requiring dedicated cloud GPUs and large memory buffers, **Tui Voice Mini runs 100% locally on-device**—in web browsers via WebAssembly, on iOS/Android, and on low-power ARM microcontrollers like Raspberry Pi and ROS robots.

---

## ⚡ Key Highlights

* **True On-Device Footprint:** Only **4.5M parameters**. Requires **< 30 MB RAM** at inference time.
* **Integrated Source-Filter Synthesizer:** Direct harmonic oscillator and filtered noise excitation—**requires zero external neural vocoder** (no separate 100 MB HiFi-GAN or Vocos needed).
* **Native Runtime Prosody Control:** Algebraic `--pitch-shift` and `--pitch-range` controls to manipulate voice timbre and pitch contour with zero latency.
* **Full Malayalam G2P Coverage:** Explicit 76-slot budget mapping covering all 59 Malayalam phonemes, long/short vowel distinctions, conjunct clusters, and explicit Chillus (ൺ, ൻ, ർ, ൽ, ൾ, ൿ).
* **Adversarial Training Lineage:** Trained for 40,000 steps with multi-period and multi-resolution adversarial GAN discriminators.

## 💻 Quickstart & Python Usage

### 1. Installation

```bash
# Clone the official repository
git clone https://github.com/Cyrax321/tui-voice.git
cd tui-voice
pip install -r requirements.txt

# Install eSpeak NG for Malayalam phonemization
# Ubuntu/Debian: sudo apt-get install espeak-ng
# macOS: brew install espeak-ng
```

### 2. Synthesize Speech with PyTorch

```python
import torch
import soundfile as sf
from tui_voice import phonemes as P
from tiny_voca.config import Config
from tiny_voca.model import TinyVoca
from huggingface_hub import hf_hub_download
import json

# 1. Download model & config from Hugging Face
model_path = hf_hub_download("Cyrax321/tui-voice-mini-ml", "tui-voice-mini-ml.pt")
config_path = hf_hub_download("Cyrax321/tui-voice-mini-ml", "config.json")
plan_path = hf_hub_download("Cyrax321/tui-voice-mini-ml", "vocab_plan.json")

# 2. Initialize model
cfg = Config.from_dict(json.load(open(config_path)))
model = TinyVoca(cfg)
state = torch.load(model_path, map_location="cpu", weights_only=False)
model.load_state_dict(state.get("model", state), strict=False)
model.eval()

# 3. Phonemize & Encode input text
text = "നമസ്കാരം, ഇത് തുയി വോയ്സ് മിനി മലയാളം മോഡൽ ആണ്."
plan = json.load(open(plan_path))
tokens = P.phonemize(text)
token_ids = P.encode(tokens, plan)

tok_tensor = torch.tensor([token_ids], dtype=torch.long)
stress = torch.zeros_like(tok_tensor)
lengths = torch.tensor([len(token_ids)], dtype=torch.long)
speaker = torch.tensor([0], dtype=torch.long)

# 4. Synthesize 24 kHz audio
with torch.inference_mode():
    audio, _, _ = model.synthesize(
        tok_tensor, stress, lengths, speaker,
        speed=1.0,
        pitch_shift=0.15,  # Locks into natural Malayalam female register
        pitch_range=0.85,  # Smooth, consistent melodic contour
        voiced_vowels=True
    )

sf.write("output.wav", audio.squeeze(0).numpy(), 24000)
print("Saved 24 kHz audio to output.wav!")
```

### 3. Lightweight ONNX Runtime Inference (Zero PyTorch Dependency)

```python
import onnxruntime as ort
import numpy as np
import soundfile as sf
from huggingface_hub import hf_hub_download

# Download ONNX model (21.4 MB) or INT8 model (5.4 MB)
onnx_path = hf_hub_download("Cyrax321/tui-voice-mini-ml", "onnx/tui-voice-mini-ml.onnx")
session = ort.InferenceSession(onnx_path)

# Run direct graph evaluation
one = lambda v: np.array([v], dtype=np.float32)
audio, durations = session.run(None, {
    "tokens": np.array([[12, 45, 23, 67, 18]], dtype=np.int64),
    "stress": np.zeros((1, 5), dtype=np.int64),
    "voice": np.array([0], dtype=np.int64),
    "speed": one(1.0),
    "pitch_shift": one(0.15),
    "pitch_range": one(0.85),
})

sf.write("onnx_output.wav", audio[0], 24000)
```

## 🔬 Architecture Specifications

| Module | Component Name | Parameters | % of Model | Function |
| :--- | :--- | :--- | :--- | :--- |
| **Embeddings** | `phoneme_embed`, `stress_embed`, `voice_embed` | 16,704 | 0.37% | Maps 76 phonemes + stress + voice into 192-dim vector space |
| **Text Encoder** | `encoder` | 1,588,864 | 35.02% | 4 Transformer blocks, 192 channels, 4 heads, RoPE attention |
| **Duration Head** | `duration_head`, `pause_head` | 123,906 | 2.73% | Predicts frame durations and punctuation pauses |
| **Prosody Predictor** | `frame_transformer_a` + `f0_head` | 795,971 | 17.54% | 2 Transformer blocks predicting continuous $F_0$ and voicing |
| **Cepstral Decoder** | `frame_transformer_b` | 1,985,984 | 43.77% | 5 Transformer blocks predicting acoustic filter coefficients |
| **Source-Filter Head** | `synth_head` | 25,862 | 0.57% | Differentiable harmonic pulse-train and noise filter |
| **Total Model** | **Complete Inference Pipeline** | **4,537,291** | **100.0%** | **End-to-End waveform generation (24 kHz)** |

## 📈 Training Convergence Metrics (Step 40,000)

Tui Voice Mini was trained on an NVIDIA L4 GPU with high-RAM for 40,000 steps using AdamW optimizer and cosine learning rate decay:

* **Validation Pause Accuracy:** `1.000` (100% exact punctuation pause placement)
* **Validation Duration Length Error:** `0.097` (< 9.8% cadence error)
* **Validation Voicing Accuracy:** `93.4%` (crisp distinction between voiced vowels and unvoiced consonants)
* **Final Pitch Error ($F_0$ RMSE):** `3.73 semitones` (down from `8.61` at step 10)
* **Discriminator GAN Loss:** `0.277` (stable adversarial equilibrium)
* **Teacher Forcing Fraction:** `0.0` (fully autonomous, free-running speech synthesis)

## ⚠️ Current Status & Known Limitations

Tui Voice Mini is released as an **experimental research prototype (v0.1-preview)**, not a commercial production system:

1. **Synthetic Timbre & Vocoding:** To achieve a ~10 MB footprint and run without an external neural vocoder, Tui Voice Mini employs a lightweight source-filter harmonic oscillator + noise generator. While speech is intelligible, it produces an audible buzz/robotic timbre compared to 100M+ parameter vocoders (e.g. HiFi-GAN, BigVGAN).
2. **Single Speaker Profile:** The model is currently trained on a single Malayalam female speaker (`female_01` from AI4Bharat Rasa). Multi-speaker or male voices are not yet supported.
3. **Number & Symbol Verbalization:** Raw digits (e.g. `123`, `2026`) and English symbols (`%`, `$`) are not automatically expanded. All inputs must be converted into full Malayalam words (e.g. `നൂറ്റിയിരുപത്തിമൂന്ന്`) before synthesis.
4. **Prosody on Long Paragraphs:** Synthesizing lengthy compound texts without punctuation pauses can result in flat or monotonous intonation contours.
5. **Pending Benchmarking Verification:** Objective intelligibility metrics (CER/WER via IndicConformer) and human subjective listening evaluations (MOS/CMOS) are currently ongoing across the 500-sentence test split.
